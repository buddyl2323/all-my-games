BUDDY GAMES — GITHUB PAGES WEBSITE

1. Extract this ZIP.
2. Go to https://github.com/new and create a PUBLIC repository named buddy-games.
3. In the repository, choose Add file > Upload files. Upload index.html, style.css, games.js (and optionally this README) to the repository ROOT, not inside another folder.
4. Commit changes.
5. Open Settings > Pages > Build and deployment. Select Deploy from a branch, branch main, folder /(root), then Save.
6. Visit https://YOUR-USERNAME.github.io/buddy-games/ (may take a few minutes).

CONNECT YOUR GAMES:
Open games.js in GitHub, click the pencil to edit, and replace each empty '' URL with the live public link for Tidal Frontier, Whisper Station, Online Shooter, and Lost City. Commit changes. The Play buttons then work.

This ZIP is a GAME DIRECTORY, not the games themselves. Keep multiplayer games hosted on Render. No server or paid domain is needed for this directory.
